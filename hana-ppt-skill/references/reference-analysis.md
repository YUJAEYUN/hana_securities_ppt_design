# 레퍼런스 분석 기록

## 목적

이 문서는 하나증권 스타일 변환기가 참고할 시각적 근거와 적용 범위를 분리해 기록한다. 레퍼런스에서 반복된 사실은 규칙 후보가 된다. 2026-08-14 사용자 승인에 따라 로컬 HFG IR 2건의 반복 규칙을 운영 프로필로 확정하되, 공식 CI 가이드로 확인되지 않은 값은 `approved estimate`로 표시한다.

## 분석 대상

| ID | 문서 | 범위 | 주된 용도 |
|---|---|---:|---|
| `hfg-1q26-kor` | 하나금융그룹 1Q26 Presentation | 25쪽 | 그룹 IR 레이아웃, 표·차트, 섹션 구분 |
| `hfg-1h26-kor` | 하나금융그룹 1H26 Presentation | 26쪽 | 반복성 검증, KPI·요약 레이아웃 |
| `hana-securities-2026-08-market-strategy` | 하나증권 리서치센터 「8월 주식시장 전망과 전략」 | 34쪽 | 예외 자료 확인; 스타일 학습 대상에서 제외 |

원본 위치와 출처 URL은 `assets/reference-decks/sources.json`을 단일 기준으로 사용한다.

## 분석 방법

1. PDF 전 페이지를 이미지로 렌더링해 접촉판(contact sheet)으로 전체 흐름을 확인했다.
2. 표지, KPI, 경영실적 요약, 섹션 구분, 차트, 계열사, 부록, 면책, 종결 페이지를 대표 표본으로 다시 확인했다.
3. 두 HFG 자료에서 같은 위치와 표현이 반복되는지 비교했다.
4. 하나증권 리서치 자료는 사용자 판단에 따라 일반적인 하나증권 스타일이 아닌 예외 자료로 분류하고 스타일 학습에서 제외했다.
5. 색상은 렌더링 이미지에서 얻은 근사 후보이며 공식 CI 값이 아니다.

## 핵심 결론

- 하나의 고정 템플릿보다 `문서군 + 슬라이드 유형 + 콘텐츠 밀도`로 규칙을 선택해야 한다.
- HFG IR은 흰 배경, 녹색 계열, 얇은 선, 플랫한 표·차트, 반복되는 상단 탐색과 하단 페이지 체계가 매우 안정적이다.
- 예외로 지정된 하나증권 리서치 자료의 표지 색상과 헤드라인은 브랜드 토큰이나 템플릿 근거로 사용하지 않는다.
- 그룹 IR에서 관찰한 원형 모티프와 `One DNA, One Promise`는 그룹 자료의 문법이다. 하나증권 자료에 무조건 복제하지 않는다.
- 생성기는 원본의 의미 구조를 먼저 분류한 뒤, 해당 문서군의 레이아웃을 적용해야 한다.

## 근거 수준

| 수준 | 의미 | 현재 예시 |
|---|---|---|
| `observed` | 실제 레퍼런스에서 확인 | 흰 본문 배경, 녹색 표 헤더 |
| `candidate` | 여러 관찰을 일반화했으나 공식 승인 전 | 근사 색상, 여백 비율, 제목 크기 범위 |
| `approved estimate` | 사람 검수로 운영 사용을 승인했으나 공식 CI 수치는 아님 | `brand.json`의 HFG IR 기반 색상·서체 역할 |
| `official` | 공식 CI 가이드로 확인 | 현재 없음 |

## 대표 기준 이미지

`assets/baselines/`에는 전체 PDF를 복제하지 않고 회귀 검사에 필요한 대표 페이지만 둔다. 각 이미지의 출처와 역할은 `assets/reference-analysis.json`에 기록한다.

## 제한과 후속 검증

- PDF 렌더링 결과는 원본 PPTX의 마스터, 정확한 폰트 크기, 개체 좌표를 보존하지 않는다.
- 근사 색상은 렌더러의 색 관리와 안티앨리어싱 영향을 받는다.
- 예외 처리된 하나증권 리서치 자료는 스타일 빈도와 좌표 산정에서 제외한다. 대표성이 확인된 추가 자료가 들어오면 새 문서군을 다시 정의한다.
- `brand.candidate.json`은 추출 당시의 검수 대기 입력으로 보존한다. 실행기는 출처·사용자 승인·한계를 별도로 기록한 `brand.json`만 사용한다.
