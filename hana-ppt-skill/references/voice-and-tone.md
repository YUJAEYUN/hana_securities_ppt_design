# 운영 문체와 말투

## 적용 범위

이 문체는 사용자가 2026-08-14에 로컬 기준으로 승인한 HFG 1Q26·1H26 IR 자료에서 반복되는 표현을 정리한 **운영 프로필**이다. 하나증권 IR 원본에서 검증한 공식 문체는 아니다. 실행 정본은 `assets/voice.json`이며, 이 문서는 판단 방법과 예시만 설명한다.

`hana-securities-2026-08-market-strategy`는 리서치 프레젠테이션이므로 문체 학습에서도 계속 제외한다.

## 관찰된 특성

1. **결론·수치 우선**: 핵심 KPI와 증감률을 먼저 보여주고, 우측 또는 하단에서 원인과 의미를 설명한다.
2. **명사형 보고체**: 제목과 불릿은 `증가`, `개선`, `유지`, `결정`, `예정`, `확보`처럼 짧게 닫는다. 본문 설명에 존대형을 사용하지 않는다.
3. **인과 관계 명시**: `핵심이익의 견조한 성장에 힘입어 … 증가`처럼 동인과 결과를 한 흐름으로 연결한다.
4. **비교 기준 동반**: 실적 수치는 `전년동기 대비`, `전분기 대비`, `YoY`, `QoQ` 등 기준과 기간을 가까이 둔다.
5. **판단 축 명명**: `수익성`, `자본적정성`, `주주환원`처럼 독자가 평가해야 할 축을 소제목으로 직접 제시한다.
6. **목표와 사실 분리**: 목표에는 기간, 실행 방안과 조건을 붙이고, 변경 가능성이 있는 내용은 주석이나 면책 문구로 구분한다.
7. **과장 억제**: 근거 없는 최상급·독점적 표현보다 측정 가능한 변화와 실행 항목을 사용한다.
8. **면책 문구 예외**: 면책 문구는 축약된 불릿체가 아니라 존대형의 완전한 문장으로 쓰며, `restyle-only`에서는 원문을 그대로 보존한다.

## 역할별 작성 패턴

| 역할 | 패턴 | 운영 예시 |
|---|---|---|
| 슬라이드 제목 | 기간·대상·핵심 주제 | `2026년 1분기 경영실적 Highlights` |
| 메시지 헤드라인 | 핵심 동인 + 결과·목표 | `차별화된 수익성 및 예측가능한 주주환원을 바탕으로 기업가치 제고 가속화` |
| 실적 불릿 | 동인 → 수치가 있는 결과 | `핵심이익의 견조한 성장에 힘입어 당기순이익 전년동기 대비 7.3% 증가` |
| 실행 방안 | 관리 대상 + 실행 방향 | `은행 핵심 경쟁력 초격차 확대` |
| 목표 | 목표값 + 기간 + 실행 수단 | `주주환원율 50% 이상, 2027년까지 단계적으로 확대` |
| 면책 | 범위·기준일·불확실성·책임 제한 | 원문을 완전한 문장으로 보존 |

위 예시는 등록된 기준 이미지에서 문체 구조를 설명하기 위해 짧게 옮긴 것이다. 자동 생성 시 예시의 사실이나 수치를 다른 자료에 복제하지 않는다.

## 변환 규칙

### `restyle-only`

- 말투를 **평가만** 하고 텍스트는 바꾸지 않는다.
- 조사, 문장부호, 영문 약어, 숫자, 단위도 잠금 대상으로 취급한다.
- 문체가 기준과 다르면 변경하지 말고 검사 리포트에 제안만 기록한다.

### `hana-refine`

- 제공된 근거 안에서 제목을 명사구로 압축하고 불릿을 `근거/조건 → 변화 → 결과` 순으로 정리할 수 있다.
- 수치, 단위, 기간, 비교 기준과 고유명사를 삭제하거나 새로 만들지 않는다.
- 전망·목표를 실적 사실처럼 바꾸지 않는다.
- 부정적 지표는 숨기거나 과장하지 않고 비교 기준과 중립적 설명을 함께 둔다.

## 검사 질문

- 제목이 한두 줄의 명사구로 핵심 판단 축을 드러내는가?
- 성과 주장마다 수치, 기간과 비교 기준이 있는가?
- 목표·전망·계획이 실적 사실과 시각적·언어적으로 구분되는가?
- 불릿이 근거 없는 최상급 표현을 사용하지 않는가?
- `restyle-only`에서 원문이 바이트 수준의 정규화 범위 밖으로 변경되지 않았는가?
- 제외된 리서치 자료의 표현이 규칙이나 예시에 들어오지 않았는가?
