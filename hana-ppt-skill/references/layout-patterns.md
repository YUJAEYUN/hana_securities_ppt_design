# 레이아웃 선택 규칙

## 선택 순서

생성기는 다음 순서로 레이아웃을 결정한다.

1. 원본 PPTX의 화면비와 페이지 역할을 보존한다.
2. 문서군을 현재 근거가 확립된 `hfg-ir` 또는 `other`로 분류한다.
3. 페이지 유형을 선택한다.
4. 콘텐츠 밀도에 따라 모듈 수와 분할 여부를 정한다.
5. 텍스트 오버플로우와 시각 회귀 검사를 통과한 변형만 채택한다.

## 공통 페이지 유형

| 유형 | 필수 내용 | 우선 레이아웃 | 넘침 처리 |
|---|---|---|---|
| `cover` | 제목, 날짜/부제, 브랜드 | 문서군 전용 표지 | 제목 재작성 후에도 길면 2줄, 3줄 금지 |
| `agenda` | 3~6개 항목 | 번호 목록 또는 섹션 맵 | 항목을 묶어 2열, 글자 축소는 최후 |
| `section-divider` | 섹션명 | 장식 모티프 + 작은 목차 | 부가 설명 제거 |
| `executive-summary` | 핵심 결론 3~5개 | KPI 카드 + 해석 모듈 | 슬라이드 분할 |
| `comparison` | 비교 대상 2~4개 | 동일 폭 열/카드 | 비교 축을 줄이거나 2장으로 분할 |
| `timeline` | 순서와 시점 | 수평 단계 또는 세로 단계 | 단계 묶음 또는 2장 분할 |
| `chart` | 결론, 차트, 출처 | 차트 우선 단일/2분할 | 보조 차트를 다음 장으로 이동 |
| `table` | 표, 단위, 출처 | 헤더 강조 표 | 열 제거·요약표 생성 후 원표는 부록 |
| `disclaimer` | 고지문, 연락처 | 흰 배경 장문 | 법정 문구는 요약하지 않고 페이지 추가 |

## 화면비

- 기존 PPTX를 다듬을 때는 원본 화면비를 유지한다.
- PDF 레퍼런스의 렌더링 화면비는 HFG 자료에서 약 `1.444:1`로 관찰됐다.
- 새 자료는 사용자가 화면비를 지정하지 않으면 초안을 만든 도구의 화면비를 유지한다.
- 기준 이미지 비교는 같은 화면비끼리만 수행한다.

## 밀도 등급

- `low`: 표지, 섹션 구분, 단일 메시지.
- `medium`: KPI 3개, 차트 1~2개, 비교 2~3개.
- `high`: 표/차트 3개 이상 또는 긴 근거 문장. 자동으로 글자를 극단적으로 줄이지 않고 우선 페이지를 분리한다.

## 동적 대화

사용자가 “더 보수적으로”, “리서치 보고서처럼”, “숫자를 더 크게”, “표를 줄이고 결론을 강조”처럼 지시하면 문서군 자체보다 해당 지시를 우선한다. 단, CI·로고 보호영역, 고지문 보존, 데이터 왜곡 금지는 유지한다.
