# 3. 레이아웃 패턴 정리

## 목적

추출된 좌표와 유형 분류를 사람이 검토해, 재사용 가능한 슬라이드 배치 규칙으로 만든다. 자동 통계는 초안이며 최종 규칙은 실제 샘플의 시각적 관례를 확인한 뒤 확정한다.

## 대상 슬라이드 유형

필수:

- 표지
- 목차
- 텍스트+불릿
- 비교
- 클로징

분석 결과가 충분할 때 추가:

- 섹션 구분
- 차트
- 표

## 유형별 문서 템플릿

각 유형마다 다음 항목을 기록한다.

1. 사용 목적과 적합한 콘텐츠
2. 그리드와 콘텐츠 영역
3. 제목, 로고, 페이지 번호 위치
4. 권장 텍스트 양과 계층
5. 도형, 선, 표, 차트의 스타일 관례
6. 넘침 처리 우선순위
7. 허용되는 변형과 금지 패턴
8. 근거가 된 샘플 슬라이드

## 좌표 기록 원칙

- 원본 단위와 슬라이드 대비 비율을 함께 기록한다.
- 좌우/상하 여백, 열 간격, 콘텐츠 시작점을 분리한다.
- 정확히 고정할 값과 범위로 허용할 값을 구분한다.
- 브랜드 값 자체는 중복 기재하지 않고 `brand.json` 키를 참조한다.

## 텍스트 넘침 처리 규칙

기본 우선순위는 다음과 같다.

1. 불필요한 문장과 중복을 줄인다.
2. 불릿 수를 줄이거나 슬라이드를 분리한다.
3. 행간과 문단 간격을 허용 범위 안에서 조정한다.
4. 마지막 수단으로만 글꼴 크기를 낮추며 최소 크기 아래로는 내리지 않는다.
5. 자동 축소로 읽기 어려워지는 경우 생성 실패 또는 경고로 반환한다.

샘플에서 다른 일관된 관례가 관찰되면 그 관례를 우선한다.

## 완료 조건

- 필수 5개 유형의 규칙이 모두 작성된다.
- 모든 규칙이 하나 이상의 샘플 근거와 연결된다.
- 고정 요소와 가변 요소가 구분된다.
- 생성기 개발자가 추가 해석 없이 좌표와 넘침 정책을 구현할 수 있다.
